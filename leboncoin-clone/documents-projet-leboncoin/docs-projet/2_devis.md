## 1. Description du projet

Développement d'un site web de petites annonces type LeBonCoin comprenant :
- Un système d'authentification complet (inscription / connexion / déconnexion)
- La gestion des annonces (création, modification, suppression, consultation)
- Un système de filtrage par catégorie, prix et mot-clé
- Un module de favoris
- Une messagerie interne entre utilisateurs
